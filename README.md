# Customer Shopping Behavior Analysis

An end-to-end **Data Analytics project** that analyzes 3,900 customer purchase transactions to uncover actionable insights into **customer behavior, spending patterns, product preferences, discount usage, subscription behavior, and customer segmentation**.

The project demonstrates a complete analytics workflow using **Python, PostgreSQL/SQL, and Power BI** — from data cleaning and feature engineering to business analysis and interactive dashboard development.

## 📊 Project Overview

The objective of this project is to transform raw customer shopping data into meaningful business insights that can support **customer retention, subscription growth, product positioning, targeted marketing, and revenue optimization**.

The dataset contains **3,900 records and 18 columns**, covering customer demographics, purchase information, shopping behavior, ratings, discounts, subscriptions, and shipping preferences.

## 🛠️ Tools & Technologies

* **Python** – Data cleaning, exploration & feature engineering
* **Pandas** – Data manipulation and preparation
* **PostgreSQL** – Database integration and business analysis
* **SQL** – Business queries, aggregations, segmentation & ranking
* **Power BI** – Interactive dashboard and data visualization

## 🔄 Project Workflow

**Raw Dataset → Python Data Cleaning → Feature Engineering → PostgreSQL → SQL Business Analysis → Power BI Dashboard → Business Recommendations**

### 1. Data Preparation with Python

The dataset was explored and prepared using Python. Key activities included:

* Dataset structure and statistical exploration
* Missing-value analysis
* Category-level median imputation for missing review ratings
* Column standardization using snake_case
* Age-group creation through feature engineering
* Purchase-frequency transformation
* Data consistency checks
* Removal of redundant `promo_code_used` information
* Loading the cleaned dataset into PostgreSQL

### 2. Business Analysis with SQL

PostgreSQL was used to answer key business questions, including:

* Revenue comparison by gender
* High-spending customers using discounts
* Top-rated products
* Standard vs. Express shipping behavior
* Subscriber vs. non-subscriber performance
* Products highly dependent on discounts
* Customer segmentation into **New, Returning, and Loyal**
* Top 3 products within each category
* Relationship between repeat purchases and subscriptions
* Revenue contribution by age group

### 3. Power BI Dashboard

An interactive **Power BI dashboard** was developed to communicate the analyzed data visually and make the resulting business insights easier to interpret.
